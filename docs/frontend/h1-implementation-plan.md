# H1 前端实施顺序

| 切片 | 交付与验收 |
| --- | --- |
| H1.0 | 核实附件范围内的 30 项检查。保存合成 3000 字流及 100/500/1000 条会话的原始性能记录。五页、四尺寸和两主题截图与对应版本关联。 |
| H1.1 | 统一错误和本机草稿存取，校验设置、评测参数及候选 JSON，恢复聊天焦点，移除自绘下拉的键盘分叉，改善共享弹窗和渲染恢复。执行 WebView2 与浏览器专项，留出真实系统读屏、DPI 及窗口手验记录。 |
| H1.2 | 验收 H1.1 后，先以受控流作为可重复比较基准，逐步分离高频订阅，测 Markdown、根与外壳提交及滚动。保留历史、引用和输出正确性。 |
| H1.3 | 将类型化 IPC 从复用最高的领域渐进迁移。保留旧命令和数据契约，覆盖返回定位和异步结果归属。工程规范以独立提交落地。 |
| H1.4 | 按用例统一语义令牌、状态、文本与控件尺寸。以 H1.0 的浅暗截图和实际键盘操作为验收对照。 |

H1.0 与 H1.1 各自独立提交。当前停点为 H1.1 验收。任何真实模型测试沿用项目的单批授权；本阶段的性能输入为合成文本和受控响应。现行视觉规范来自 [HTML 原型](../design/html-prototype-ui.md)，交付状态见 [H1.1 验收](h1-1-acceptance.md)。
