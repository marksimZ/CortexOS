# H1.0 界面截图基线

在非活动 Windows 桌面启动 H0 原生 WebView2。用合成工作区保留一条 3,000 字回答和三个已确认知识节点。覆盖四种内容视口与两套主题，共 40 张实际页面截图。截图以 `{页面}-{light|dark}-{宽度}.png` 命名，位置为 `artifacts/phase-h1/final-baseline/` 中原生截图测试的输出目录。

| 页面 | 800×600 | 1366×768 | 1600×900 | 1920×1080 |
| --- | --- | --- | --- | --- |
| 对话 `chat` | 浅、暗 | 浅、暗 | 浅、暗 | 浅、暗 |
| 知识 `knowledge` | 浅、暗 | 浅、暗 | 浅、暗 | 浅、暗 |
| 图谱 `graph` | 浅、暗 | 浅、暗 | 浅、暗 | 浅、暗 |
| 评测 `benchmark` | 浅、暗 | 浅、暗 | 浅、暗 | 浅、暗 |
| 设置 `settings` | 浅、暗 | 浅、暗 | 浅、暗 | 浅、暗 |

40 个视口中，文档的 `scrollWidth` 均未超出视口。该检查覆盖页面外框。800×600 的局部滚动区、超过一屏的表单与抽屉需结合任务操作继续检查。截图在首个可见标记后拍摄，评测部分样本可见固定题库加载状态。鼠标物理拖动、Windows 实际缩放、系统高对比度和读屏交互另列人工项。
