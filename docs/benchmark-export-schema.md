# Benchmark 报告协议与重新评分记录

2026-10-29，切片 7。标准和个人批次使用同一协议；早期没有批次的开发单题记录继续由原详情接口读取。

## JSON v1

根字段：`reportSchema=cortexos.benchmark-report`、`schemaVersion=1`、`createdAt`、`applicationVersion`、`contentHash`、`payload`。

`payload` 包含：工作区/用途、原报告（全计划统计和冻结计划）、原题库元数据、每个批次项目的完整题目、运行配置/硬件/源码身份、模型快照、caseRuns、全部尝试、实际执行/请求上下文快照、保存消息、实际事件、全部原评分和独立评分、原始资源采样、冻结价格来源。

未运行项目保留 null/空尝试，不虚构执行记录。缺失指标维持 null，错误与状态原样保存。原报告使用原评分，不选择重新评分中最好或最新的结果。全部尝试明细与汇总采用首个尝试的既有口径分别保留。

内容标识定义为 `SHA256(serde_json::to_vec(payload))`：对象键采用该序列化器的字典序，保留 JSON 数值表示；不是 RFC 8785/JCS 或数字签名。应使用保留数值表示的解析器核对；JavaScript 将 1.0 改写为 1 等转换后重新序列化不能直接当作同一字节协议。Rust 的 `validate_report` 提供本协议读取/校验，已保存 JSON 可解析并复核。哈希用于一致性检查，不作为来源真实性背书；本轮没有外部报告导入、覆盖数据库或签名功能。

读取前后核对同连接 `total_changes()` 和 `PRAGMA data_version`。期间发生写入就停止导出并要求重试；不交付混合状态的快照。文件保存发生于快照生成之后，后续任务变化不会改写该文件。

## CSV v1

UTF-8 BOM、CRLF、固定表头；所有值加双引号，内部双引号翻倍，保留单元格内换行。每个尝试×评分版本一行；无尝试/无评分时保留对应占位和状态。列包含批次/题库/内容身份、模型名和编号、题目/轮次/序号、运行/尝试/实际执行 ID 与状态、评分来源/独立轮次/版本/hash、题目/回答/原生工具字段、评分指标/依据、配置/请求/硬件和价格快照。

以 `= + - @` 开头（含前导空白/BOM）或起始 Tab/CR/LF 的单元格添加文本前缀单引号。CSV 是便于表格审阅的投影；前缀和空值表示不是字节保真的原文。完整审计及原始字符串以 JSON 为准，CSV 的源报告 hash 标识对应的 JSON payload。

## 私密数据与保存

固定查询只读取当前批次及其真实执行/固定资料，不读取凭据配置或系统密钥库的内容用于导出。连接拥有的配置、模型检查元数据及其事件副本移除结构化认证字段；问题、回答和工具 Schema 不做通用键名删除，保留题目语义。原配置/请求哈希指向原始保存记录，导出文件自己的 contentHash 指向经过这些移除后的 payload。

自由文本可能包含用户原本写入的私密信息，导出界面明确包含题目、回答、资料和请求快照；本功能不承诺扫描任意文本里的所有秘密。当前协议不开放未来隐藏能力/认知题库的导出。

保存使用系统对话框。取消不写文件；用户选定路径后，在同目录创建唯一临时文件，完整写入并 sync，再以不替换目标的 Windows MoveFileExW 原子提交。失败仅清理本次确实创建的临时文件，不覆盖既有文件；其他平台的硬链接提交失败同样停止，不回退为覆盖。磁盘断开/断电的全路径人工验收另列，不能由类型检查代替。

## 独立重新评分

复用 `benchmark_evaluations` 的追加记录，新增的 `details_json.regrade` 对象包含 `(workspace, batch, sessionId)` 关联、来源评分 ID/输出 hash、实际批次轮次/模型/题目序号、case hash、输入 hash、引擎版本/实现指纹与沙箱策略。实现指纹覆盖评分器、JSON/工具处理、Python执行及依赖锁文件。

预览不写记录。确认时重新核对当前输入 hash，只对已有原评分的已完成新版回答操作；旧协议、未运行、取消/失败的执行和没有原评分的记录保留原样。编程回答仍只走原 Docker 隔离，不下载镜像、不在宿主机运行。全局任务占用避免与聊天/评测竞争；取消或计算/校验失败整体撤销本轮，所有新评分在同一个事务提交。

计算出的 Scoring Error、Execution Error、Needs Review 等作为各自状态记录，不冒充答题错误。页面按保存数、已评分数、通过数分别呈现，并可查看每项完整依据；原统计仍独立。历史轮次及明细按20条读取，导出包含全部轮次。原评分选择显式排除 regrade 记录，原消息、尝试/运行状态、Token、费用及执行事件均不重写。
