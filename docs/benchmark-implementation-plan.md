## 页面操作规范

保留现有外壳与Tokens。实验入口先显示有状态的实验列表和“新建评测”；没有实验显示真实空状态，不放演示排名。表单按模型→测试集→重复次数组织，高级参数展开，开始前汇总计划调用数、预计条件和未就绪项。

监控页顶部为实验名称、状态、完成数/计划数和“停止”；主体使用模型分组的逐题列表。完成数只统计真正终结项，unsupported/blocked另列，ETA只有测量足够时提供。切页不取消；重新进入读取已保存状态。正在停止时避免重复点击，确认终态后再提供继续。

比较以可排序语义表格为主，能力/速度/资源分组，列出样本量和缺失值。缺失显示“不可用”，原因按需打开；不显示虚假零值。筛选两份不同数据集或配置时给出差异，不直接冠以“最佳模型”。少量分组条形图只作补充，所有数值可从表格读取，采用直接标签及颜色以外的区分；该取舍参照UI/UX技能的比较图建议，实际材质仍按项目HTML规范。

单题详情使用固定标题/关闭、正文滚动、必要时固定底部；展示输入、原文、评分依据、条件和执行链接。成功提示沿用2.5秒，失败和草稿保持可见。高级术语在详情保留准确定义，主任务使用“首字延迟 / 生成速度 / 已用资料 / 继续未完成项”等可理解的文案。
