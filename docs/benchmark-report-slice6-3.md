## 交互与真实性

- 标准和个人评测继续共用结果组件，范围参数沿用原只读接口的工作区/用途检查。浏览器不读取数据库或模型服务。
- 面板从全局标题栏以下打开；标题、刷新和关闭入口不随正文滚动。底部“返回结果列表”和当前结果页的“上一题/下一题”保持可用，首尾正确禁用。跨页切换和深链接不在本轮扩展。
- 默认阅读已有 Markdown；“原文”保留完整原始字符串、空格和换行。无原始回答不显示伪造的答案；未发送、运行无文字、不支持、读取失败和执行错误分别呈现。
- 评分依据保留已保存的全部记录；标准答案、题目规则、响应 Schema 与工具定义按需展开。固定资料显示原资料编号和从 1 开始的行号，不称其为生产知识库检索命中。
- 展开可查固定题库/模型计划、已保存的运行设置、模型检查、请求内容与上下文清单。云端记录有实际 wire 时展示该记录，避免将本地兼容存储参数当作真实云端请求。
- 耗时/资源和原始采样复用已读取的数据。执行/评测事件均来自原接口；有真实执行记录才提供 3D 定位，未运行题目没有该按钮。
- 详情响应绑定工作区、用途、批次和题目身份；切题立即隐藏前一题，晚到请求由 effect 清理标记和响应身份双重拒绝。切题重置正文滚动位置，手动刷新仍为只读操作。
- 活动批次中未评分的当前题按需轮询；得到保存评分、关闭面板或切题即停止旧轮询。全计划统计、排序、筛选和分页分母保持原样。
