## 验收依据

1. 1366×768、1600×900、1920×1080 浅深主题检查；整页无横向溢出，横向表格在自身区域滚动。
2. 初次多模型加载保持报告顶部；显式翻页/单题链接仍定位；加载不显示未取得的总数。
3. 滚动时运行/刷新及当前模型分页可达；焦点不被固定栏遮挡；抽屉固定关闭/返回与全局窗口操作保持。
4. 外观菜单、筛选和详情可用方向键/Enter/Esc/Tab 完成；长答案不截断，长文件名仍保留扩展名。
5. 以明确标记的未运行大计划测量概览/页/单题的 IPC 时间和响应字节；交互时间含自动化往返，不能当作模型速度或纯渲染耗时。读取不发模型请求、不改计划统计。
6. 先代码逻辑审阅、类型检查和构建，再必要实际 UI 专项；不跑无关单元套件。测试数据、失败修正、实际命令和未测边界记入里程碑。

真实系统 150%、读屏、跨硬件长时任务、Docker 与付费云端不由本轮自动化替代；保持用户系统设置。现有用户验收窗口若已关闭则直接更新；若发现仍运行，先请用户保存并关闭，不强制结束。

## 实测结果（最终桌面构建）

独立 WebView2/SQLite，900 项未运行计划，3 个受控模型标签，每模型每页 20 项，总计 60 个已渲染列表项。各读取按同一进程顺序取 5 次，未清理系统/磁盘缓存；耗时从 WebView2 调用前至返回解析完成，不是纯 SQL 耗时。字节为返回对象重新序列化后的 UTF-8 大小，不包含 IPC 传输封装。

| 操作 | 样本数 | 耗时中位数 | 最小–最大 | 返回 JSON 字节 |
| --- | --- | --- | --- | --- |
| 概览（3 模型汇总，不含回答） | 5 | 152.5 ms | 142.4–153.4 ms | 48,891 |
| 单模型第 8 页（20 项） | 5 | 10.2 ms | 8.2–18.3 ms | 11,353 |
| 单题详情（未运行） | 5 | 70.1 ms | 52.8–73.5 ms | 798 |
| 点击翻页至新行出现（含自动化往返） | 5 | 68.7 ms | 58.4–76.9 ms | 不适用 |

完整样本：`artifacts/benchmark-6-5-native-final/benchmark-report-usability-85967-nd-running-controls-visible-desktop/performance.json`。这些结果只描述当前设备/受控计划，不推广为所有机器或已完成 900 条长回答的性能。没有清空缓存、测纯渲染 FPS 或估算模型生成速度。读取/翻页/关闭检查期间模型请求为 0，前后计划统计相等；随后单独发送 1 条未结束的受控 HTTP 响应，滚动到最后模型仍可停止，没有发送剩余 899 项。

外观菜单复核可正常展开、选择、Esc 收起且不误关详情；FileName 在三尺寸真正截断主体名并保留 `.py`，因此这两个共享组件未修改。新增表格区域有名称、可聚焦并接受键盘滚动；这属于功能检查，不声称完成 WCAG 认证或真实读屏验收。
