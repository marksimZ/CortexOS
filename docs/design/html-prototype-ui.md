# HTML 参考界面规范

## 2026-10-29：区分全局导航与知识列表

基础栏的分栏图标只控制全局导航，悬停提示明确展开/收起全局导航。知识页使用树状列表图标及“知识列表”文字按钮控制局部列表，提示和aria-expanded随状态更新，并通过aria-controls关联列表。避免不同层级面板使用同一无文字图标。

## 2026-10-29：去重标题与控件比例

非对话页只在全局基础栏显示页面名称；内容区的同名h1保留读屏语义并视觉隐藏。纯标题行移除，知识列表操作与图谱模式切换继续保留。设置分类和图谱分段选项统一13px文字、20px行高、30px选项高度、3px外层内距及6px图文间距。图谱数据选择器34px高，左内距12px，右侧为箭头预留32px；保持现有表面、焦点和弹出菜单。

## 2026-10-29：全页面统一窗口基础栏

对话、知识、图谱、评测、设置共用 AppShell 顶部48px基础标题栏，保持文档流布局、不随内容压缩，标题及空白区域可拖动。禁止将非对话页窗口控件绝对定位到业务卡片右上角；业务标题和操作放在下方内容区。全局窗口操作始终可见可用，弹窗沿用下移及独立关闭规则；输入框、菜单与按钮继续响应自身操作。

## 2026-10-29：Benchmark 导出与独立评分

复用报告操作栏、AppDialog、SelectMenu、Toast 与当前 Tokens，统一标准/个人入口。导出先选择 JSON/CSV，再进入系统保存窗口；取消是正常操作，失败保留错误及重试，不以点击按钮当作保存成功。重新评分按范围预览、明确确认、独立历史和逐题依据组织；固定标题/关闭与底部操作，长标识换行，20条分页。运行中关闭/Esc取消本轮，离开批次时清理未完成任务；全局窗口操作始终可用。不新增视觉体系或主页面说明卡片。

## 2026-10-28：Benchmark 长报告收尾

沿用原布局与 Tokens。报告初次加载保留顶部；明确翻页/题目定位才滚动，后台刷新不抢走阅读位置。运行操作固定于报告滚动区顶部，当前模型分页紧随其下；测量实际操作栏高度并为焦点预留空间，个人报告步骤导航不与固定栏叠加。固定栏将原表面色叠到背景色形成遮挡，避免文字透出；无新色板或动画体系。加载仅显示已知页码，读失败保留重试。长标识允许断行，横向表格有名称和键盘焦点；FileName 及外观菜单保持既有组件。

## 2026-10-28：Benchmark 报告定位

沿用现有报告、列表、单题抽屉和语义 Tokens。报告页提供“打开定位链接”；单题固定标题提供“复制定位链接”。所有链接均为应用内 `#/benchmark?...`；无系统协议注册。返回结果保留筛选、页码和题目；关闭抽屉后回到触发项，直接链接打开则回到本题列表项。找不到目标或条件不匹配时保留错误与重读/清除条件入口；加载新目标期间隐藏旧题和旧批次。全局窗口操作、弹窗独立关闭及原有阅读/原文、评分、来源、采样入口保持。布局继续采用用户 HTML 规范，不新增设计体系。

2026-10-22。用户明确要求用 `reference/CortexOS 3D_ Full Prototype(1).html` 完全替换此前视觉设计。此规范取代 V3 的视觉方向；原业务边界、数据真实性和可打断图谱操作继续有效。

## 参考与落地

直接读取 HTML 的 CSS 与布局，并用 Edge 打开四页截图对照；参考的外部 Google Fonts 请求在检查中阻止，不引入线上字体依赖。参考配色：背景 #EEF1F7、蓝雾 #DAE2FB、绿雾 #D4EEE8、主文字 #1B2230、强调 #4F5BD5、知识青绿 #4FB6A8。采用本地字体回退，中文使用系统 UI 字体。

外层16px留白与16px区域间距；侧栏252px，聊天正文最大720px，依据栏336px；知识页列表290px，设置页200px标题列与最大640px表单。浅色半透明玻璃、20px面板圆角、12px条目圆角和胶囊按钮均来自参考。暗色使用参考的深蓝绿背景；字体普通/中/粗权重从400/500/600调整至380/450/500，避免系统中文字体在550时匹配到过粗字重。深色强调色为可读性调整至#7F8BFF，非逐像素不加判断地照抄。

现有功能比参考多，使用相同控件和折叠详情容纳，不删除审核、对比、来源、检索、运行、跨页定位、视图保存、错误或草稿保护。演示冲突、向量检索、重排器、虚构统计及Git式提交不接入正式界面。依据栏只显示既有get_run返回的当次知识和估算量，SVG连线只表示纳入本次请求。

## 五项细节

1. 主层级靠参考背景与1%–3%的细微表面叠色。2026-10-27 按用户新规范收敛为单层内嵌轮廓，替代早期双环输入框；次级按钮默认无框线，悬停用背景变化反馈，保留键盘焦点提示。
2. 外观支持浅色、深色、跟随系统，偏好保存在本机；暗色降低文字权重，图谱配色随主题同步。
3. 仅新到达的回答片段以小范围blur/opacity依次呈现，已显示正文不反复播放，输入编辑与引用原始偏移不变；按钮图标用统一盒子和居中排列。
4. UI数字使用tabular-nums，容量和计数保留稳定空间；网格用minmax与断点适应窗口，标题balance、正文pretty并保留中文断行。
5. 窗口拖动复用系统能力，反馈采用短时弹性运动，成功提示2500ms自动消失；错误、待处理和未保存状态保留。减少动态效果时取消模糊/弹性，图谱镜头继续遵循独立用户选项。

## 2026-10-22 交互补充：菜单、滚动和面板操作

保留上述视觉方向和页面排布。本次只统一共享交互，实际命令、问题修正和截图见里程碑同日“界面易用性优化”。

- 应用内单选菜单统一复用`SelectMenu`。保留真正的select、原label、value、disabled和change事件，用浏览器Popover顶层呈现选项，避免被玻璃面板或模态窗口裁切。选中勾选、键盘方向/Home/End/Enter、Esc、点击外部关闭和焦点状态保持一致；不支持Popover的环境保留系统选择器。文件选择和日期等系统能力继续沿用原控件。
- 菜单背景、文字、选中态、12px圆角与阴影使用现有Tokens。选项至少34px高，长名称换行；位置根据视口边界调整，可向上展开。弹出列表的可访问名称使用“字段名＋选项”，避免与原字段重名。
- 滚动沿用浏览器能力：10px轨道、2px透明内边形成约6px可见滑块、透明背景、无上下箭头；悬停/拖动只改变颜色。浅深主题各自设滑块Tokens，强制颜色模式保留系统可见性。阅读区域保留稳定滚动占位，内部滚动不把外层页面一起带走。
- 长面板采用共享`panel-header / panel-body / panel-footer`结构；标题及关闭按钮不参与正文滚动，有保存/确认操作时固定底部。覆盖处理记录、引用、历史、资料文件、知识与关系编辑、图谱/执行详情和窄窗导航。保留错误、保存禁用及未保存修改确认。
- 版本历史为非模态抽屉，通过React Portal挂到body，避免页面玻璃表面和顶栏形成的层叠遮挡；原有版本选择、跨页定位与关闭焦点处理不变。
- 回答依据在面板标题行右侧收起，窗口按钮独立留在上方；关闭后在聊天区右侧提供展开入口。桌面展开偏好本机记忆，窄窗临时展开独立管理，跨断点不覆盖桌面偏好。窄窗使用原生模态dialog，支持Esc及关闭后返回展开入口。

验证区分浏览器、原生WebView2和系统设置：1366×768、1600×900、1920×1080检查浅深主题；375/800为内容视口检查，600px高度用于长表单/文件预览压力检查，不等于修改Windows缩放。2026-10-23用户确认已在真实150%系统缩放下验证所有功能，反馈无问题；真实读屏仍待人工补充。下文的“本轮”验证结果保留当时记录，后续验收以windows-delivery和milestone-log为准。

## 文件与验收

### 2026-10-27：输入、滚动与分屏微调

在现有页面和状态管理上实现，不改数据库、Provider、知识或图谱相机逻辑。

- 输入法组合输入期间 Enter 交给输入法；compositionend 后 500ms 内拦截发送回车，Shift+Enter 继续换行，点击发送保持显式发送行为。
- 聊天按正文实际行高计算阈值：向下滚动至底部一行内恢复跟随，向上滚轮/触摸/滚动/阅读按键暂停；距离底部超过三行才显示“回到最新内容”。新内容与布局变化观察继续复用实际消息；关闭浏览器自动滚动锚定，防止浏览器与应用争抢位置。
- 轮廓使用内嵌阴影，分隔线使用 inset shadow；去掉按钮默认边框与嵌套重复框线，保留强调按钮、选中状态和可见键盘焦点。菜单外圆角12px、间距4px、内圆角8px关联计算；侧栏等明确嵌套区域采用同单位的 `max(0px, 外圆角 - 内边距)`，间距越过外弧时内角归零。
- 聊天回答依据与资料文件预览使用共享 PaneDivider，位于既有列间距内，不新增布局列。拖动期间透明遮罩和 Pointer Capture 防止误选正文；Esc、失焦或取消恢复初始比例；双击/Enter 均分，方向键调整，主内容超过80%后松手收起右侧预览，并保留恢复入口及焦点。拖动结束前保留预览以便 Esc 取消；窄窗继续使用已有单栏/抽屉模式。
- 比例根据当前容器与缩放后的指针坐标换算。聊天顶栏同步为实际依据栏宽度留位，避免均分后遮住模型状态或外观控件。
- 资料列表、标题和导入预览使用 FileName：只截断文件主体名，最后一个扩展名完整保留；完整名称仍在 DOM 和 title 中，资料版本号单独一行。

专项检查、命令和截图证据见同日里程碑。原生自动化使用合成 composition 事件，不代替实体中文输入法手工连按验收；CSS zoom 检查不等同于 Windows 系统缩放。此前150%系统缩放验收仍属于旧版本记录。

重建AppShell和统一样式入口，保留页面业务组件与后端接口。新增AppearanceControl、Toast、ChatEvidence，调整Chat/Markdown呈现并复用现有模型/会话/知识逻辑。旧多层覆盖CSS退出运行入口。仅前端和文档变化，Rust/迁移/模型请求逻辑不改。

验证先类型与构建，再浏览器实际截图；检查1366×768、1600×900、1920×1080、窄窗和深色，最后选择必要原生专项覆盖聊天Markdown、上下文引用、知识版本、来源与图谱。按用户要求不跑单元或无关全量测试。实际结果写入milestone-log。完成后停在本轮UI验收，不推进Decision Lab。
