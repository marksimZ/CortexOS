# H4 发布准入清单

**正式发布决策为 No-Go。** 项目授权由维护者暂时保留待定，生产 Windows 签名材料和实际更新托管仍待批准。候选包仅用于内部验收。

| 验证项 | 依据 | 正式发布条件 |
| --- | --- | --- |
| 正式身份、版本、可复建候选 | [发布工程](h4-release-engineering.md) | 核准正式版本、Windows x64 标识与安装范围。 |
| 安装、历史升级、凭据、恢复、默认和主动卸载 | [安装矩阵](h4-install-upgrade-validation.md) | 保留隔离来宾实测证据以及手动操作结果。 |
| 更新与 Authenticode | [发布工程](h4-release-engineering.md) | 分别验证更新签名、公钥和渠道，以及 Windows 信任、签名者和时间戳。 |
| 内容与许可证 | [第三方许可证](h4-license-audit.md) | 审批项目授权及实际随包声明，核对适用的许可证原文、源码和变更说明。 |
| 完整性 | Dry Run `candidate.json`、`SHA256SUMS.txt` 与解包清单 | 核对最终分发字节、签名状态和下载文件 SHA-256。 |
| 发布操作 | 当前为本地 Dry Run | 维护者单独批准发布渠道和公开发行。 |

本阶段交付与发布准入独立记录。整合工程与实际验收结果后停在 H4 验收点，再进入 H5 产品体验阶段。
