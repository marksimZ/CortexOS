# Phase H0 性能复核

## 测量条件

2026-11-20，同一 Windows x64 主机、非活动桌面、原生 WebView2、1600×900 内容视口。G0、G5、H0 均用 debug custom-protocol 可执行文件。每次启动用 SQLite Backup API 从同一只读固定测试库还原副本。复测使用只提供元数据的回环端点，未连接真实模型；RAG 固定评估使用 FTS5 和关系查找。未重启、未清系统缓存。实际启动顺序 `G0 → H0 → G5 → G5 → H0 → G0`，已用 profile 再按 `G5 → G0 → H0 → H0 → G0 → G5`。启动终点含 WebView2 页面探测和 `bootstrap`。原始记录见 `artifacts/phase-h0/comparison.json`、`resources.jsonl`、`comparison-summary.json`。

## RAG 预览实测分解

同一 H0 源码另编含临时测点的诊断程序；业务代码已恢复，测点不进入交付程序。两路各 40 次。命令与 Rust worker 在同一单调时钟测量，WebView 用 `performance.now()`。资料组装包含证据、预算、版本追踪、清单和模型请求预览。以下均为 ms。

| 观测范围 | 词语预览 P50 / P95 | 显式关系预览 P50 / P95 |
| --- | ---: | ---: |
| WebView IPC 往返 | 5.300 / 5.900 | 6.100 / 6.700 |
| Rust 命令总耗时 | 2.801 / 3.194 | 3.708 / 4.042 |
| 任务派发与回收（命令减 worker） | 0.090 / 0.142 | 0.101 / 0.132 |
| 路由与上下文前置检查 | 0.595 / 0.736 | 0.590 / 0.777 |
| 词语召回含 SQLite FTS5、排名与行映射 | 0.521 / 0.559 | 0.525 / 0.601 |
| 关系与冲突处理整体 | 0.959 / 1.181 | 1.874 / 2.153 |
| 其中：图关系扩展 | 未启用 | 0.876 / 1.039 |
| 资料与请求组装 | 0.379 / 0.492 | 0.382 / 0.498 |
| Rust 命令外 IPC 残差（逐条相减） | 2.494 / 2.888 | 2.312 / 2.735 |
| 前端交互，点击至预览首个结果写入 DOM（n=20） | 7.300 / 9.900 | 未测 |
| 前端处理，IPC 响应完成至首个结果写入 DOM（另一轮 n=20） | 1.138 / 1.594 | 未测 |

词语与关系两路都未执行语义向量、RRF 或重排。图关系候选处理在关系段内。向量候选融合路径见 [RRF 与重排计时](../../apps/desktop/src-tauri/src/rag.rs)，本批没有该路径的可比数据。数据库路径耗时包含取行和映射；`EXPLAIN QUERY PLAN` 在只读测试库中确认 FTS5 虚拟表索引用于 MATCH，存在排序临时 B-tree；关系 SQL 使用边及版本关联、查找时自动覆盖索引与排序。详见 `artifacts/phase-h0/query-plans.json`。相关实现为 [FTS5 查找](../../apps/desktop/src-tauri/src/retrieval.rs)、[关系查找](../../apps/desktop/src-tauri/src/knowledge_graph_retrieval.rs)、[上下文组装](../../apps/desktop/src-tauri/src/db.rs)、[预览命令](../../apps/desktop/src-tauri/src/commands.rs) 和[前端预览](../../apps/desktop/src/ContextPicker.tsx)。

前端处理另用 WebView2 DevTools 的 `Network.loadingFinished` 与 `MutationObserver` 配对，并以请求开始时间对齐时钟。该段包含响应解码、前端更新及提交，止于 DOM，未测显示器呈现。证据见 `artifacts/phase-h0/profile-network.json`。

IPC 命令外残差是最大的单段观察值，含请求桥接、序列化和响应调度。关系扩展是后端显式关系路径的主要增量。表内各段分位数基于各自样本，不能相加成整条链路的分位数。诊断详情见 `artifacts/phase-h0/profile.json`、`profile-summary.json` 与 `rag-profiling.patch`。没有修改召回、排名、上下文组装或者索引。

## 图谱和真实模型

G5 曾在固定 24 节点下做到单独及并行相机操作各 230 个 `requestAnimationFrame` 间隔，P50/P95 均为 7.00/7.10ms，真实并行 GPU 请求 6534.49ms，整卡峰值约 4.34 GiB。该证据来自 G5，用作参照。

H0 独立授权后实际向 Ollama 转发两次请求，按顺序执行。测试模型为 `qwen3:4b-instruct`（指纹 `0edcdef34593…`），本地 GPU、2048 上下文、每次最多 64 输出 Token、60 秒超时、`keep_alive:0`。测试库与原生窗口隔离。两次开始前以 `/api/ps` 确认无已加载模型，完成后又确认归零。无重试或云端请求。

| 场景 | 端到端或图谱帧间隔 | 整卡显存观察峰值 |
| --- | --- | ---: |
| 空闲对照 3 秒 | 应用进程树 RSS 峰值 463,785,984 字节 | 1422 MiB |
| 真实标准评测：Core 60 v2 `math-001` | 批启动至结果轮询命中 9625.02ms；API 响应 8465ms；Ollama 加载 8218.49ms；正确答案 `95`，`Passed` | 3856 MiB |
| 24 节点，单独拖动 | 231 个帧间隔，P50/P95 7.00/7.10ms，最大 7.40ms | 1466 MiB |
| 24 节点，与真实对话请求并行 | 对话完成 2628.54ms。230 个帧间隔，P50/P95 7.00/7.10ms，最大 7.10ms | 3937 MiB |

进程每约 0.5 秒、整卡每约 1 秒采样。显存峰值包含 Windows 和其他程序，占用更短的瞬时峰值可能落在采样间。图谱观察窗约 1.6 秒；执行事件显示首批模型响应约在发起请求后 2.45 秒出现，因此这次帧间隔对照主要覆盖请求等待及加载窗口。持续解码期间的图谱压力、大图谱并行与开机冷启动仍未测。两次真实请求各只有一个样本，不能计算有意义的推理延迟 P50/P95。原始证据为 `artifacts/phase-h0/h0-live.json`、`h0-live-resources.jsonl`、`live-summary.json` 和 `graph-chat-events.json`。
