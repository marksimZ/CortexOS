# H3 固定负载性能回归

## 可复测口径

测试使用 Windows x64、Tauri custom-protocol 调试构建和独立的 WebView2 与 SQLite。启动测量从创建进程计到实际 IPC bootstrap 返回。新 WebView2 配置与复用配置分别计时。Windows 文件页保持系统管理；系统冷开机另列。

记录原始测量、中位数和最近秩 P95。小样本的 P95 可能等于最大值。CPU 使用计时器差分，并按逻辑核数归一化。进程工作集可能含共享页，另留 Private Bytes。句柄数为 Windows 进程的所有句柄，无法单独拆分文件句柄。整卡显存、使用率及 WebView2 进程数按采样时点记录。SQLite 事务按真实接口结果和完整性核查验证。

初始对照来自 [G0](../optimization/performance-baseline.md)、[G5](../optimization/phase-g5-release-validation.md) 与 [H0](../release/h0-performance-review.md)。数据集大小、窗口条件或回环服务不一致时只列并排观测。实际 GPU、实际 CPU 模型与模拟模型的时间不作速度比较。

## 重放入口

在 `apps/desktop` 完成 `npm.cmd run build` 和离线锁定的 custom-protocol 调试构建后，设置 `CORTEXOS_NATIVE_ONLY=1`。

| 场景 | Playwright 入口和数据 |
| --- | --- |
| 新与旧浏览器配置启动、空闲、词语检索、知识导入、切换工作区并打开图谱 | `CORTEXOS_H3_BASELINE=1`，运行 `--project=h3-baseline`。默认 60 秒空闲，`CORTEXOS_H3_IDLE_SECONDS` 可设 30–900 秒。两个固定工作区、隔离知识文本和只读资源采样。 |
| 长聊天、断线、取消及异常退出 | `--project=desktop chat.spec.ts`，可用 `CORTEXOS_CHAT_SOAK_MS=120000` 运行 120 秒固定流。 |
| 混合检索与索引取消 | `--project=desktop rag-native.spec.ts`，实际 SQLite、可控向量和固定模型回复。设置 `CORTEXOS_H3_RAG_TIMINGS=1` 可记录 8 次发问到读取执行详情的时间。 |
| 千节点图谱 | `CORTEXOS_GRAPH_BASELINE=1`，运行 `--project=graph-baseline`；固定 100、500 和 1,000 节点，包含逐页载入。 |
| 标准评测与报告 | `--project=desktop standard-benchmark.spec.ts`，使用固定回环和现有 Core 60 题目，含批次停止、恢复及导出。 |
| 项目工具调度 | `CORTEXOS_HARNESS_EXPERIMENT=1`，运行 `--project=harness-experiment --grep "G5 three tool queue"`。需本机 Linux Docker 及 G5 的三个已验证工具镜像和隔离快照。`CORTEXOS_H3_HARNESS_SAMPLE=1` 另存持有资源、Aider 执行中和重启恢复后三个观测点。 |

在用户使用电脑期间，Windows GUI 测试使用非活动桌面。真实本地模型调用需按有界批次单独确认。

## 实测结果

| 标准场景 | 样本数及观测 |
| --- | --- |
| 新 WebView2 配置启动 | 3 次，P50 / P95 为 697.03 / 2,276.95 ms，首跑是本组最慢。 |
| 已用 WebView2 配置启动 | 3 次，P50 / P95 为 678.38 / 723.84 ms。 |
| 空闲期间检查应用是否响应 | 91.85 秒里 17 次 bootstrap，P50 / P95 为 5.72 / 7.40 ms。 |
| 词语检索预览 | 20 次，P50 / P95 为 7.32 / 8.93 ms，均命中指定工作区的已生效知识。 |
| 文件导入 | 同一约 7 KiB 文档的 8 个版本，读取、核验并入库的 P50 / P95 为 12.07 / 14.00 ms。原生文件选择使用隔离测试路径。 |
| 工作区切换和图谱开关 | 两个工作区交替 12 次，P50 / P95 为 466.17 / 490.69 ms。每个工作区有 80 个合成图谱节点与 160 条连线，第一个工作区再加入一条检索用知识。 |
| 长流式对话 | 固定回环持续 120.60 秒后取消，SQLite 保留 754 字符。同套专项含端口失效、半段断线、协议错误、手动重试、应用强制退出和重新打开。 |
| 混合检索与回答 | 8 次发问到界面完成、读取执行详情的 P50 / P95 为 479.17 / 506.94 ms。向量与生成均使用固定回环。 |
| 千节点图谱热读取 | 1,000 点、5,000 边，读取整图 3 次的 P50 / P95 为 555.50 / 590.18 ms。按页获取节点与连线为 154.76 / 182.67 ms。单次首批显示 232.91 ms，加载全部页另计 628.74 ms。静止 350 ms 内没有绘制。 |
| 标准评测运行 | 完整停止恢复及导出回归中 11 次完成尝试的 P50 / P95 为 1,370 / 1,480 ms。等待取消回归中 8 次完成尝试为 824.5 / 1,377 ms。只统计已完成的固定回环请求，两个批次分别报告。 |

原始工件位于本地 `artifacts/phase-h3/` 的 `chat-soak/`、`graph-baseline/`、`benchmark-lifecycle/`、`diagnostics-rag-final/`。聊天和标准评测的数值由隔离 SQLite 中的起止时间只读计算。

同一台 Windows 11 10.0.26200，i7-12800HX、24 个逻辑核、可见内存 16,898,142,208 字节，WebView2 视口 1600×900。空闲与切换观测来自 `native-baseline-final/**/h3-native-baseline.json`。

| 资源 | 空闲 18 样本 P50 / P95 | 切换 4 样本 P50 / P95 | 回到对话后 3 样本 P50 / P95 |
| --- | ---: | ---: | ---: |
| 应用进程树工作集（字节） | 497,233,920 / 501,710,848 | 549,517,312 / 560,599,040 | 533,733,376 / 555,171,840 |
| 应用进程树 Private Bytes | 314,935,296 / 375,377,920 | 475,723,776 / 483,319,808 | 356,892,672 / 380,280,832 |
| Windows 句柄数 | 3,924 / 3,954 | 3,953 / 3,953 | 3,947 / 3,956 |
| WebView2 进程数 | 6 / 6 | 6 / 6 | 6 / 6 |
| 应用进程树 CPU（整机容量归一化） | 0.02% / 0.08% | 2.62% / 2.69% | 0.06% / 0.10% |
| 整卡显存（字节） | 1,510,473,728 / 1,577,058,304 | 1,525,153,792 / 1,539,309,568 | 1,516,240,896 / 1,516,240,896 |

CPU 使用相邻样本差分，各列分别为 17、3、2 个间隔。关闭图谱后 Private Bytes 中位从 475.7 MB 降到 356.9 MB，仍高于首次打开图谱前。本次采样支持观察退出图谱后的释放。多小时工作集、文件句柄分类和操作系统冷开机均待补测。独立测试库的 SQLite 快速完整性检查返回 `ok`，外键异常 0。

## Docker 队列观测

在获准后从非活动桌面临时启动本机 Docker Linux 29.9.2。三工具队列共测量一轮，专项耗时 37.3 秒。测试请求只走固定回环，三个采样点不用于估算 P50/P95。

| 采样时点 | 进程树 RSS | Private Bytes | 句柄数 |
| --- | ---: | ---: | ---: |
| 持有资源的标准评测 | 424,304,640 B | 269,271,040 B | 3,267 |
| Aider 执行中 | 478,662,656 B | 339,939,328 B | 3,885 |
| 强制退出重开并清理后 | 421,539,840 B | 264,298,496 B | 3,272 |

三个时点均为 6 个 WebView2 进程。整卡显存分别为 1,525、1,488、1,488 MiB，含系统与其他程序。进程树数值未计入 Docker 虚拟机内部占用。测试前后应用归属容器均为 0，Docker 恢复关闭。原始证据见 `artifacts/phase-h3/harness-live/` 与 `harness-docker-postcondition.json`。
