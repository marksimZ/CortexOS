# H2 备份与恢复验证

## 后端专项

在 \`apps/desktop\` 执行 \`cargo test --manifest-path src-tauri/Cargo.toml --offline --locked --lib portability::tests\`。测试由独立临时目录生成数据。

| 场景 | 实际验证 |
| --- | --- |
| 全量备份与跨实例恢复 | 源数据库保有非空 WAL。验证导出及恢复后知识可通过 FTS 查到，恢复前备份仍保存目标原工作区与界面偏好。已存在的目标备份文件保持不变。 |
| 工作区范围与合并 | 两个源工作区、一个目标工作区。验证其他工作区内容和草稿未导出，原有目标工作区保留；同编号拒绝恢复，匹配的共用内置题库按版本复用。扫描整个解包后的 SQLite 文件确认无用作标记的外部工作区词。核对项目历史事件的追加顺序。 |
| 历史评测 | 恢复后读取 Core 60 v1 的数据集版本和原评审器版本。历史结果从备份恢复，保持原评分内容。 |
| 损坏、结构异常和失败恢复 | 分别提交截断 ZIP、重新计算哈希但加入异常视图的数据库、确认后改写的暂存文件。失败后原工作区依旧可读。 |
| 空间不足 | 在启动切换的同一生产判断路径注入可用容量 1 字节，返回空间不足，重新打开后原工作区仍可用。由注入模拟空间不足。 |
| 旧库迁移 | 用真实第 7 条迁移结构生成备份，隔离恢复后迁移到当前版本，源数据库仍处于第 7 条结构。 |
| 恢复中断 | 第一次切换后不提交界面恢复确认，再启动时仍可读取同一个恢复编号，未再次替换数据。确认后归档到历史。 |
| 知识导出与敏感字段 | 校验 JSON 和 Markdown 只携带所选工作区内容；前端传入的非白名单密钥字段未进入备份。 |

首次专项检查发现，删行后重建全文索引的工作区备份仍保留了其他工作区的索引词。实现改为从空库写入数据并重建索引，4 项专项复验通过。

## Windows 验证条件

使用 Windows x64 的独立非活动桌面运行 WebView2 调试应用。源实例和目标实例分别使用新建的数据目录和浏览器配置。回环地址指向未使用的测试端口。所有样本、知识及测试密钥均为合成数据。正式产品安装身份及真实跨电脑安装升级由 H4 验证。

设置 \`CORTEXOS_NATIVE_ONLY=1\` 后运行 \`playwright test --project=desktop data-portability-native.spec.ts storage-recovery-native.spec.ts storage-native.spec.ts\`。正式复验 3 项通过，总计 40.4 秒。初次在命令沙箱内启动时 WebView2 没有创建渲染页。改用非活动桌面隔离运行后，Windows 打开和保存对话框、WebView2 重启和缓存检查均成功。

- 两个独立配置完成全量备份、包内容校验、知识导出和恢复。目标工作区中的原数据进入安全备份。确认草稿与深色偏好恢复，云端配置仍使用原连接编号但需要重新绑定。对 ZIP 解包后的每个条目扫描合成密钥，均未命中。通过本机设置成功重新绑定同一连接，未发送模型请求。
- 验证存储清单逐项大小、来源及快照引用，并保留用户放入的无关文件。缓存可预约、取消、归档和复原。再次归档后观察 WebView2 自己重建代码缓存目录及索引。拒绝未确认的清理，确认后清理旧副本，当前重建缓存及无关文件仍在。
- \`cargo test --manifest-path src-tauri/Cargo.toml --offline --locked --lib storage::\` 最终 2 项通过。存储专项需要读取 Windows 父目录句柄，常规沙箱拒绝该读取。在已批准的测试环境中通过。
- 此次真实 UI 证据为本地 \`artifacts/phase-h2/final/\` 中的 1366×768 备份预览、1600×900 恢复确认、1920×1080 恢复结果，以及缓存确认与结果。合成备份 22,826 字节，恢复前安全备份 22,177 字节，知识 JSON 1,106 字节，清理后的旧缓存记录为 291,591 逻辑字节。耗时包含启动、文件对话框和测试控制，单一样本仅用于验收。

最后重新构建桌面程序，运行 \`playwright test --project=desktop standard-benchmark.spec.ts\`，2 项通过，共约 1 分钟。使用固定回复回环替身，覆盖排队、停止与恢复、报告 JSON / CSV 保存及不重发等待任务。实际日志为 \`artifacts/phase-h2/native-standard-regression.log\`。
