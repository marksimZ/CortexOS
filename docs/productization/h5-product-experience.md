# H5 产品体验

## 工作流审计与处理

| 工作流 | 已确认的界面问题 | H5 处理与入口 |
| --- | --- | --- |
| 首次启动、建工作区 | 空界面只给建工作区入口，模型检测和恢复入口分散。 | 沿用对话空状态，展示 Ollama 检测结果，提供本机、云端、备份恢复和跳过入口。创建仍只填工作区名称。 |
| 本机连接、普通对话 | 探测结果和模型选择分处标题栏与设置，连接失败时需要找入口。 | 首次使用可直接进入「模型连接」。进入工作区后仍可先管理知识。聊天沿用原来模型设定、发送、停止和重试。 |
| 云端连接与个性化评测 | 旧的空状态只建议本机模型。进入云端设置前需要工作区。 | 引导中的云端操作先创建工作区，再打开「云端模型」。个性化任务的记录和详情沿用有效密钥准入。 |
| 对照不同工作区的设置 | 浏览器回归发现，设置分类纳入链接后，切换工作区会回到默认的模型连接。 | 切换工作区或在设置中创建工作区时保留分类，按新工作区加载该分类的数据。 |
| 导入、检索、查看依据和图谱 | 空知识列表只提示手动创建或从回答保存。新手可能找不到资料导入。 | 空列表指明「资料文件」。知识页帮助优先展示索引与版本，原有检索、来源和图谱定位链路沿用。 |
| 标准评测、查看历史 | 运行与报告只能从评测页发现，离开后需要找回原批次。 | 任务中心显示当前状态、处理题数、等待说明和可用的取消操作，可定位批次和原报告的继续入口。 |
| 个性化评测 | 任务中心需要区分题库生成与批量评测，避免跳错步骤。 | 根据保存的任务类型定位报告或题库审核。题库审核继续要求保留或设置使用偏好。 |
| 项目适配 | 工具运行状态、组合实验和分析版本分散在原页面。 | 展示对应任务和状态，任务历史可打开对应分析版本的测试区，组合实验可定位具体报告。 |
| 备份与恢复 | 首次使用前需要自行找到设置下的本地数据。 | 首次使用和任务中心都提供直达。恢复沿用验包、冲突提示、暂存和重启。 |
| 常见错误 | 状态和原因散布在各业务抽屉，首屏帮助容易挤占内容。 | 当前视图的帮助主题靠前，在独立面板展开。任务中心显示已保存的错误摘要，保留原记录的现场和操作。 |

## 任务中心

- 「当前任务」读取现有 TaskSlot。共享任务与存储操作各自提供运行状态，工作区任务按所选工作区过滤。应用级存储与诊断可在任一工作区查看。
- 「最近记录」读取当前工作区最近 32 条已有记录，包含对话、标准与个性化评测、模型检索对照及有执行记录的项目任务。个性化历史仍经原有云端准入检查，普通本机任务可独立显示。
- 等待中显示前序资源条件，可单独取消；开始、停止、容器清理和记录收尾沿用业务模块。能够停止运行的项目在有明确作用域时提供停止入口。其他任务可打开原模块操作。
- 批量评测显示实际已处理题数和计划总量。已处理包含通过评分流程、记录执行错误或记录取消的条目，正确率与覆盖率仍在原报告中分别查看。没有可核对总量的任务显示运行状态。错误摘要沿用前端脱敏。
- 历史跳转保留工作区和可核验记录标识。对话失败从原消息重试，批量评测按原报告规则继续未发送题目或补评分。索引、诊断及存储操作沿用各自的状态和记录入口。
- 任务状态只在抽屉打开时刷新。关闭抽屉即停止读取，切换工作区时按新工作区重新读取。抽屉标题和关闭按钮固定，Windows 全局标题栏始终可见。

## 实施边界

使用既有工作区数据库和队列，无数据库迁移、依赖升级或模型策略变化。新增的本机偏好仅记录是否跳过空工作区引导。知识导入、云端传输、备份和工具执行继续走原权限与确认流程。验收队列、场景和正式发布条件见 [H5 验收](h5-acceptance.md)。
