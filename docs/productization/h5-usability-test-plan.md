# H5 可用性测试计划

## 测试条件

使用 Windows WebView2、隔离 SQLite、独立 WebView2 配置和一次性文件。无外部受试者时可用内部走查。记录每条路径从首次操作到成功或阻断的耗时、失败位置、重复操作和实际观察。自动化用例可记录脚本失败及耗时。真实用户的求助次数、误操作与主观难度由受试者实测补充。

| 场景 | 实施步骤 | 成功条件 |
| --- | --- | --- |
| 普通 AI 用户 | 从空数据启动，检查 Ollama 状态，打开模型设置，创建工作区，发送问题；再运行一次并从任务中心停止；在失败记录中回到原对话重试。另在无服务状态跳过后重启，走一次云端配置入口。 | 首次检测不触发生成；无需云端凭据即可对话；取消和失败记录可查；重启后跳过有效；打开个性化评测仍需准入。 |
| 知识管理用户 | 通过文件入口添加 Markdown，确认导入，保存知识并审核。编辑后检查旧版与来源，打开知识查找提问，从回答定位依据和图谱。验证撤销仅影响后续检索。 | 文件快照和旧版可定位，证据指向实际版本；索引错误时保留可用检索路径；空状态与帮助中的操作名称一致。 |
| 开发者用户 | 选择项目资料并查看适配报告和原文，跑本地标准题，制造一次资源等待，从任务中心取消等待，释放资源后完成运行，再打开对应历史报告。点开个性化评测验证准入。 | 本地标准评测独立可用；取消等待只影响目标任务；处理题数来自记录；适配报告可重开，来源可核对。 |
| 补充数据回归 | 打开备份与恢复入口，创建可核验备份，在隔离目录暂存、恢复并重启。 | 工作区和相关历史可恢复，两个目录可区分，原用户数据库无操作。 |

固定回环响应验证端到端功能、UI 和错误处理。真实本机模型、真实云端请求和新一轮性能对照各需独立环境和授权。物理缩放、多屏、系统滚动条与真实触控交给具备设备的验收人。

## 证据

- 新增 [H5 原生用例](../../apps/desktop/tests/h5-product-native.spec.ts)记录引导、停止、错误恢复、工作区隔离和帮助。
- 复用标准评测、知识、资料、检索、项目适配、备份及个性化门槛的已有原生用例。标准评测队列用例通过任务中心操作取消并返回报告。
- Playwright JSON 报告保存实际场景时长与失败栈。截图随具体用例保留，统计只纳入实际执行。
