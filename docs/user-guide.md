# 使用指南

适用版本：v0.1.0。首次安装见 [开始使用](getting-started.md)。

## 定时提醒（开发版）

进入工作区，在对话框输入“每个工作日下午六点提醒我写日志”，按 Enter。核对提醒内容、本地时间和接下来三次日期，选择“确认保存”。也可以输入“十分钟后提醒我喝水”创建单次提醒。时间不明确时可在草案中填写；创建提醒无需连接模型。

点击标题栏的“任务中心”查看本工作区的提醒与记录。编辑后可改期，暂停后可恢复，取消后保留记录。工作日指周一至周五。应用运行时显示当前工作区的到期提示；完全退出后会在下次启动核对计划。最多补发最近一次迟到不超过五分钟的提醒；长期离开时，多期错过合并记录。可在所属工作区的提醒历史查看结果。

### 定时收集公开新闻

在聊天里输入“每个工作日早上九点整理 AI 新闻”，核对查询词、开始日期和接下来的触发时间，点击“确认启用”。只写“早上”时可以在草案里补上具体时间。启用后，每到约定时间，应用会把查询词发给 Bing News，保存最多五条标题、来源摘要和原文链接。

从标题栏打开“任务中心 → 提醒历史”，展开对应日期的新闻简报即可回看。无结果、连接失败及退出时未完成的查询会显示各自的状态。计划同普通提醒一样可以改期、暂停或取消，应用运行时执行，重启按五分钟补发窗口处理。简报直接收录搜索摘要，不消耗模型推理或 Brave 配额。

## 我的助手（开发版）

在“设置 → 我的助手”填写名称和回答指令，例如“先列风险，再列进展，计划中的事项单独列出”。保存草稿供以后编辑；选择“发布并启用”后，本工作区接下来的本地聊天请求采用这个版本。发布列表可查看指令、启用旧版本，也可以恢复内置默认。回答的处理记录会保留当时实际使用的版本。

本片复用已有模型和知识设置，云端生成沿用内置指令。

### 使用国内云端模型

1. 打开“设置 → 云端模型 → 添加连接”，选择 DeepSeek 官方、阿里云百炼（北京）或硅基流动。填写相应平台的 API 密钥并保存。可为同一平台的多个账号填写不同的连接名称。密钥保存在 Windows 凭据管理器。
2. 刷新模型列表，或选择“手动输入模型标识”并填写厂商控制台中的模型 ID。刷新只读取目录。选择“验证生成回答”再确认时，会发送固定测试文本，服务商可能收费。
3. 在“设置 → 运行方案”新建云端方案，将“生成回答”设为刚验证的模型，保存并启用。回到聊天即可看到模型与连接名称。每次发送前可核对目标服务和共享内容，历史对话留在本机。

DeepSeek 官方预设用于生成回答。百炼预设使用北京地域密钥，可分别验证对话和向量模型。硅基流动还支持重排序模型。要用于知识检索，请按相应用途验证模型，再到运行方案中分别选择。云端向量索引沿用工作区的知识授权与建索引确认。

聊天使用非流式接口。选择百炼模型时，请选支持非流式文本生成的型号，部分仅支持流式输出的开源型号无法通过生成验证。[百炼模型说明](https://help.aliyun.com/zh/model-studio/deep-thinking)

### 在聊天里查资讯

在对话中输入“人工智能”等主题，点击“联网查询”，工作台会直接向 Bing News 读取公开新闻，无需密钥或订阅配置。可以阅读最多五条标题和摘要，打开来源，或选择“依据来源回答”，让当前模型整理资讯。普通聊天沿用原有发送方式。搜索失败时页面显示原因。

需要通用网页搜索时，可在“设置 → 我的助手 → 网页搜索”保存 Brave Search API 密钥，再在聊天输入区选择查询服务。查询词只发送给所选服务。模型使用的链接和摘要会附在聊天问题里；阅读文章全文可打开来源。可选密钥存放在 Windows 凭据管理器，支持移除。

## 工作区与对话

工作区隔离会话、知识、文件资料与图谱。切换工作区不会把正在生成的回答写入另一个会话；当前一次只执行一个生成任务。

输入框编写 Markdown 原文，眼睛图标预览排版，再返回编辑。问题和回答支持标题、列表、引用、代码及表格；回答可切换「原文 / 排版」，复制保留 Markdown。当前没有公式和代码语法着色，远程图片只显示说明。

生成中可以停止；取消、失败或超时保留已收到的回答并记录状态。重试产生新的执行记录。已发送消息会保存，未发送草稿和未保存编辑不要当成重启后可恢复的数据。

## 查看一次回答的依据

会话默认开启自动查找已确认知识，也可以关闭。手动选用优先；预览显示本次可能选用的知识、版本和容量，发送时重新校验并保存实际请求。

回答的处理记录包含真实事件、配置、知识版本和请求快照。3D 执行轨迹将这些已保存事实转成节点，可定位原消息与当时的知识版本。旧运行没有请求快照时会保留缺失状态。

`[资料1]` 或 `[资料1:2-3]` 对应该次请求中的知识文字，可点击查看；编号只在这一次回答内有效。位置检查可提示无效编号、越界行和缺少引用，但不判断回答内容是否正确。文件起源与后续编辑的知识内容应分别核对。

## 建立和维护知识

1. 从回答选中文字后保存为知识，或在知识页新建。
2. 填写标题、正文与修改原因，保存草稿。
3. 检查完整内容后确认，使该版本用于后续查找和回答。
4. 再次修改生成新草稿，旧生效版本继续使用，直到确认新版本。

「版本历史」从知识详情打开右侧抽屉，可查看旧内容、审核记录和版本差异。知识页与图谱详情复用编辑和审核操作。版本冲突需先核对变化，不能直接覆盖他人的新版本。

当前检索是中文双字词与拉丁词的词法匹配；单字、同义改写可能找不到。确认知识表示用户审核，并非系统核实事实。手动选择仍受版本、文件启用状态和容量限制。

## 使用资料文件

在知识页打开「资料文件」→「添加文件」，在系统选择器中明确选择单个 UTF-8 `.txt` / `.md`，最大 2 MiB。预览后确认导入，选择行范围保存为知识草稿，确认后才可用于回答。

应用保存文字副本，不修改、监视或自动同步原文件。行号以应用保存的文字为准。原文件更新后需重新选择导入，新增版本；旧引用仍指向旧副本。

停用文件后，从该文件建立的知识停止未来检索或选用；旧回答和执行记录继续保留。停用不是永久删除，历史对话文字也不会随之消失。

## 浏览知识图谱

「知识关系」使用当前工作区的数据库节点和关系；单独标记的演示图仅供体验，不写入工作区。

- 左键拖动旋转，右键拖动平移，滚轮缩放；节点列表也能选择对象。
- 选中节点查看知识、来源、关系与版本；添加、修改和停用关系会保留历史。
- 「展开直接关联」支持从多个中心查看邻域，按批次继续读取；收起展开只改变浏览范围。
- 搜索和筛选影响当前展示，不修改知识；暂时隐藏的选中对象仍可从详情核对。
- 「保存视图」保存视角和位置；移动节点不产生知识版本。恢复已保存视图会放弃当前未保存布局。

「图例与操作 → 镜头过渡」默认平滑 420ms，可改为跟随系统或立即切换。执行图在「图例与记录说明」提供同一设置；拖动和滚轮可打断动画。关联展开保留当前镜头，必要时使用「适应当前视图」。

WebGL 不可用时，仍可用列表与详情查看、编辑知识。图上空间接近不代表两个节点存在关系；关系含义以真实连线与详情为准。

## 离线与数据保留

本地模型服务停止时，已保存的消息、知识及处理记录仍可查看。关闭编辑器或正常关窗时会提示处理未保存内容；强制结束进程可能丢失未保存编辑。数据备份方式和升级边界见 [安装指南](getting-started.md)。
