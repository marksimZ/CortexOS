# Harness Fit Lab Phase D 补齐交付

2026-11-14，入口为「评测 → 项目适配」。本次补齐首版验收后保留的任务类型、项目隔离评分、真实模型对照与报告指标。

## 使用方式与范围

- 在「测试任务 → 生成候选任务」选择 Python 调用链、原生工具调用或权限审批题。调用链题保存固定文件、行号与顺序，支持 2–5 个显式导入的直接调用。发布后可选本地模型单题评分。工具和审批题校验实际结构化请求，词句描述、错误工具名、错误参数和多余调用均无法通过，对应工具只记录请求。
- 在「测试任务 → 编程任务草案」选择跨文件修改、仓库回归、补写测试或数据库兼容性。绑定 2–8 个快照文件，合计最多 24 KB，从既有 `.py` 文件中明确允许修改的路径。跨文件题要求实际修改至少两个文件。补写测试保持业务代码及评分入口只读。数据库兼容题带只读 `.sql`，可在隔离环境使用 Python 标准库 SQLite 复现既有数据。原代码、参考实现和错误实现均运行实际编译与评分，全部满足发布条件后由人工批准。
- Codex、Claude Code 与 Aider 共用固定文件清单。每次在临时 Docker 副本内编辑现有批准路径，目录、任务说明和其他文件只读。副本校验清单、权限、内容哈希，保存逐文件修改，再清理并切换到独立评分容器。编译、每项断言、权限拦截及恢复清理各有记录。使用既有镜像、防护策略、数据库和用途隔离，原仓库保持只读。
- 「组合实验」新增加权通过率、耗时和费用条形图，保留精确表格。编译和断言分别统计，未执行、未通过与不适用独立记录。工具内部审批次数在无数据时显示未知，独立显示本批人工启动确认及真实的工具或应用权限拒绝。组合推荐至少要求每组覆盖三道不同的任务，并满足既有可比性、区间和加权结果条件。

当前项目执行支持使用 Python 标准库的选定文件、固定函数入口及 SQLite 临时数据库。调用链限于显式 Python 语法。任意构建命令、第三方依赖安装、新建或删除项目文件、原仓库写入及 OpenHands/Cursor 执行属于扩展范围。
