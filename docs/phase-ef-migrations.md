# Phase E 与 Phase F 迁移兼容性

Phase D 已发布迁移历史保留。Phase E 从 12 起增加检索和知识范围。Phase F 从 18 起增加模型运行与用量。

| 版本 | 新增或更新 |
| --- | --- |
| 12 | 本地向量索引和工作区配置 |
| 13 | 文件片段、坐标和 FTS5 索引重建 |
| 14–16 | 知识事实日期、固定快照、实验分支与已登记关系修订 |
| 17 | 不可修改的固定检索报告 |
| 18–21 | 工作区云端连接、运行方案、按连接授权的知识版本、独立云端索引 |
| 22–25 | 用量与费用预留、任务路由、隐私选项、本地向量用量 |
| 26 | 模型组合对照、报告指纹和中断状态 |

打开旧库时核对版本和历史校验值，再通过 VACUUM INTO 创建升级前备份。待执行的迁移在同一事务中运行，失败时回滚。启动恢复把未完成实验标为中断，保留已保存的题目结果及已发送的请求状态。重新运行产生新实验。正在执行且尚未保存结果的题目与已完成题分开显示，结果未知的请求保留费用预留额。

各阶段的数据库检查使用隔离库。迁移 26 以 v25 和已有固定回放为基准，注入 SQL 失败验证原库仍可读，再读取升级前备份并应用正确迁移。重启后残留实验标记为中断，历史回放仍可读，外键检查为零项错误。相关命令见 [里程碑](milestone-log.md)。

已有聊天、知识审批、执行及引用快照沿用原表。旧本机向量索引继续读取，文件片段重建后可获得语义召回。密钥保存在 Windows 凭据管理器。跨版本回退使用升级前备份，并保留新版本数据副本。旧版程序会拒绝无法识别的新版迁移历史。
