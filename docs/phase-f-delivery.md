## F7 评分、用量和费用

- 计划冻结策略、题集、模型及指纹、配置、费用上限和本地设备偏好。云端接收范围是内置合成资料和题目，授权写在隔离副本。两组串行使用新建隔离会话，保存实际采用的查找和回退。
- 新运行使用 cortex-rag-response-rubric-2，分别核对回答要点、引用准确率及召回率。日志保留题接受「保留期」「保留期限」「保留天数」等明确的等价表述，用相同日数及知识版本判断答案和引用。引用还须指向实际发送的资料，编号及行范围有效，支持紧邻引用的要点。无引用的可回答题的引用召回为 0，引用准确率无分母。其他改写、复杂否定、跨句推理和非固定措辞拒答可能需人工复核。历史记录保留当次评分版本。失败、停止、未运行及中断分别保留。
- 应用采用登记费率和服务用量估算费用。余额检查同时覆盖工作区预算和整组实验，未结算请求保留预留额。供应商价格变动、服务用量与预估差异、税费需向服务商核对。缺少用量或费用时显示未知。
- 资源为系统 CPU 区间值和整张 NVIDIA GPU 设备读数，包含其他应用占用。模型 Token 与生成用时来自服务响应和应用调用测量。按 A 后 B 顺序运行，加载顺序会影响延迟。报告单列建索引用时。

## 桌面验收方法

在合适的桌面打开独立构建的 `artifacts/cortexos-phase-ef-final.exe`。先用「固定回放」确认题库和历史。再切到「模型组合对照」，选择要对照的模型与策略，核对确认窗的题数、发往云端的范围或本地设备。完成或停止后，进入一道题查看实际执行图和评分，导出 JSON 核对题库指纹、已选资料、实际用量和费用状态。新实验和原有聊天分别在对应入口查看。

数据库变更和回滚路径见 [迁移兼容性报告](phase-ef-migrations.md)，改动全量见 [文件清单](phase-ef-files.md)。
